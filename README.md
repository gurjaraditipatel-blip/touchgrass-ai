# 🌱 TouchGrass AI — Your Digital Detox Companion

**Touch Grass. Touch Life. Feel Better.** 🌿

🔗 **Live Demo:** [touchgrass-ai.streamlit.app](https://touchgrass-ai.streamlit.app/)

TouchGrass AI is a fun, interactive web application designed to encourage people to take a break from their screens, spend more time outdoors, build healthy daily habits, and reconnect with the real world.

Instead of endlessly scrolling, turn your outdoor time into an adventure! Complete daily missions, track your progress, and make every day a little greener. 🌍

## ✨ Features

- 🏡 **Daily Missions** — Discover fun activities that encourage you to step outside.
- 🎮 **Play Together** — Explore interactive activities and challenges.
- 🎯 **Daily Goals** — Set outdoor time targets and work toward healthier habits.
- 📊 **My Journey** — Track your progress with interactive checklists and a 100-point scoring system.
- 🗺️ **Adventure Planner** — Get ideas for outdoor activities and plan your next adventure.
- 🌿 **Fun & Interactive UI** — Enjoy a colorful, beginner-friendly experience.
- 📥 **Download Your Plan** — Save your outdoor adventure plan for later.

## 🎯 Why TouchGrass AI?

Spending too much time in front of screens can make it easy to forget the world outside. TouchGrass AI encourages small, achievable steps toward a more balanced digital lifestyle.

Whether it's taking a short walk, enjoying nature, or spending time with friends, every little step counts!

## 🚀 Run Locally

Want to run TouchGrass AI on your own machine?

### 1. Clone the repository

```bash
git clone https://github.com/gurjaraditipatel-blip/touchgrass-ai.git
cd touchgrass-ai
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the environment

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
source .venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
streamlit run app.py
```

The app will open in your browser, usually at `http://localhost:8501`.
